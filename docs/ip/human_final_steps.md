# MSALS — Human Final Steps Checklist

**All items below require HUMAN action. AI assistance stops at draft preparation.**

---

## Patent Filing Steps

### Provisional Patent Applications (Priority: High)

- [ ] **Review invention disclosures** (docs/ip/invention_disclosures.md)
  - 7 disclosures covering core innovation families
  - Verify accuracy of inventor names, dates, descriptions

- [ ] **Review claim drafts** (docs/ip/claim_drafts.md)
  - 14 claims (7 system + 7 method)
  - Engage patent attorney for refinement

- [ ] **Conduct prior art search**
  - Use keyword packs from IP_STRATEGY_AND_ASSETS.md
  - Search: Google Patents, USPTO, Espacenet
  - Document findings in prior art report

- [ ] **Prepare formal figures/drawings**
  - System architecture diagrams
  - Flowcharts for each method claim
  - UI mockups showing novel features

- [ ] **Select filing approach**
  - Option A: Self-file via USPTO EFS-Web ($320/provisional)
  - Option B: Patent attorney filing ($1,500-3,000/provisional)
  - Option C: LegalZoom guided filing ($500-1,500/provisional)

- [ ] **File provisional applications**
  - URL: https://www.uspto.gov/patents/apply
  - Establishes 12-month priority date
  - No formal claims required (but include drafts)

- [ ] **Calendar 12-month deadline** for non-provisional conversion

### Non-Provisional Applications (12 months after provisional)

- [ ] Refine claims with patent attorney
- [ ] Complete formal specification with figures
- [ ] File non-provisional before provisional expires
- [ ] Consider PCT filing for international protection

## Trademark Filing Steps

### USPTO Trademark Registration

- [ ] **Complete TESS search** (see trademark_checklist.md)
  - Search: MSALS, VisionaryAI, VisionaryAI.MDALS
  - Document any conflicts found

- [ ] **Determine filing basis**
  - 1(a) Use in Commerce — if product is live
  - 1(b) Intent to Use — if pre-launch

- [ ] **Prepare specimens of use**
  - Screenshot of app showing mark in use
  - Marketing materials with mark

- [ ] **File applications**
  - URL: https://www.uspto.gov/trademarks/apply
  - TEAS Plus: $250/class | TEAS Standard: $350/class
  - File for Class 009 and Class 042

- [ ] **Monitor examination** (3-4 months)
- [ ] **Respond to office actions** (if any)
- [ ] **Monitor opposition period** (30 days after publication)
