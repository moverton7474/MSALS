## Pre-Filing Checklist

### Step 1: Preliminary Search
- [ ] Search USPTO TESS (Trademark Electronic Search System) for each mark
  - URL: https://tmsearch.uspto.gov
  - Search both word marks and phonetic equivalents
  - Check for similar marks in classes 009 and 042
- [ ] Search state trademark databases for conflicts
- [ ] Google search for unregistered but active use of similar marks
- [ ] Domain availability check (msals.com, msals.io, etc.)

### Step 2: Use Documentation
- [ ] Screenshot first use in commerce (product UI showing mark)
- [ ] Record date of first use for each mark
- [ ] Collect specimens showing mark as used (app screenshots, marketing)

### Step 3: Application Preparation
- [ ] Determine filing basis:
  - Use in Commerce (Section 1(a)) — if already in use
  - Intent to Use (Section 1(b)) — if not yet launched
- [ ] Prepare description of goods/services
- [ ] Select Nice Classification classes
- [ ] Prepare specimens of use (screenshots, packaging)

### Step 4: Filing (HUMAN ACTION REQUIRED)
- [ ] File via USPTO TEAS Plus or TEAS Standard
  - URL: https://www.uspto.gov/trademarks/apply
  - Filing fee: $250-$350 per class per mark
- [ ] OR file via attorney (recommended for multi-class)
- [ ] OR use LegalZoom/similar service for guided filing

### Step 5: Post-Filing
- [ ] Monitor USPTO office actions (3-4 month review period)
- [ ] Respond to examiner requests within deadlines
- [ ] Monitor for opposition during publication period (30 days)
- [ ] File Statement of Use if filed under Intent to Use
