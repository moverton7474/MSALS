# IP Strategy and Asset Checklist (MSALS)

## Portfolio goals
Build an IP moat around *how* MSALS transforms objectives into adaptive, multi-modal lessons and how it scales through QR + voice + rights-aware licensing.

## Suggested patent families (high level)
1. **QR-Activated Adaptive Lesson Transformation**
2. **Reverse Learning → Musical Structuring**
3. **Learner-Profile Modality Orchestration**
4. **Adaptive Musical Reinforcement Feedback Loop**
5. **Rights-Aware Educational Transformation + Licensing Requests**
6. **Instructor/Facility Avatar Attribution for AI Teaching Assistants**
7. **Pluggable Music-Generation Provider Interface for Educational Outputs**

## Trade secrets (keep confidential)
- Weighting/heuristics for cognitive-to-musical mapping
- Prompt orchestration and evaluation harness
- Personalization scoring logic
- Partner routing + licensing conversion playbooks

## IP asset pack to generate (before filings)
- Invention disclosures (1 per patent family)
- Draft claim sets (system + method)
- Specification outlines + figure descriptions
- Prior art search keyword packs
- Trademark list (VisionaryAI, MSALS, VisionaryAI.MDALS, etc.)
- Evidence log: dated docs, screenshots, commits, product demos

## Human-in-loop filing policy
Automation can prepare drafts and forms, but a human must approve:
- account creation confirmations
- payments
- final submission/filing actions
