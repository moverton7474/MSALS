# MSALS Product Description
**Music-Driven Adaptive Learning System (MSALS)**

## What it is
MSALS is a learning system that converts **learning objectives** into **personalized learning experiences**, anchored by **original, genre-based music lessons**. Students learn through the modality that fits them best (auditory via song, visual via graphics, kinesthetic via interactive prompts), guided by a **voice-first teaching assistant**.

## Who it’s for
- **Students:** learn content faster and retain more through engaging, personalized formats
- **Teachers:** distribute personalized instruction at scale using QR codes—without extra prep
- **Facilities:** museums, training centers, youth programs—turn exhibits/modules into learning journeys
- **Partners:** publishers and platforms can offer “learning mode” without building the engine themselves

## Core differentiators
1. **QR-activated learning:** teacher/facility QR codes instantly trigger the right lesson
2. **Personalization:** students receive different outputs from the same QR code, based on their profile
3. **Original music generation:** genre-based learning songs (country/rap/R&B/gospel) created on demand
4. **Voice-first interface:** students and teachers interact conversationally—no manual navigation
5. **Rights-aware transformation:** unlicensed content is not transformed; users can request licensing access

## Business model (high level)
- Free student tier
- Teacher/school plans (seat or usage-based)
- District/enterprise (multi-tenant, compliance, analytics)
- Platform licensing/API for publishers and content platforms
